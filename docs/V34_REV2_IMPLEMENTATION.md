## 今回の実装

- 単店を保持。全仕訳に部門ID。釣具店／物件ごとの不動産／漁業／本社を集計。部門の利息後利益合計と全社経常利益の当月差額を毎月検算。
- 部門画面：当月・年度累計・前年同期差分・物件展開・直近３期・通期部門ROA。２期連続赤字への弱いアシスト。決算書の「事業別収支」から開く。共通預金は部門資産から除外、本社配賦は外部売上比による参考値。
- 不動産：３年目から、ワンルーム・木造家屋・小規模事務所ビルの３候補を３か月ごと生成。価格・家賃・利回りに整合範囲。取得時の築年に応じて償却・銀行期間を固定。土地は償却しない。
- 取得翌月から家賃・入退去・敷金返還・外部管理・修繕。各区画の月次稼働は独立した簡略モデル（長期賃貸契約の更新は扱わない）。敷金は負債。
- 融資：既存スコアと格付けを使用。物件は格付けA/B/Cの期間上限25/20/15年、LTV90/80/70％。耐用年数由来の期間と両方で制限。既存元金返済を差し引き、物件NOIの80％を返済原資へ加算。基準金利＋0.5ポイント。費用は自己資金。取得失敗時に借入だけ残らない。
- 漁業：船・漁具480万円（税抜）、８年償却。船長35万円１人、船員18万円２人まで、社保15％。店舗とは別枠。通常20日・抑制12日・休漁。採用月能力半分。不漁・休漁でも給与と維持費を負担。
- 漁獲量＝販売量＋鮮度ロス。鮮度ロス５％。当月に全量外販し入金、販売単価600〜800円/kg。税率はrev2の指定を優先してゲーム10％。継続在庫・自店への振替は初版の対象外。
- 投資前12か月の損益・最低月末預金を同じ月次エンジンで試算。漁業は翌月船長、その後２か月で船員を１人ずつ採用する仮定。悪化ケースは稼働率▲20ポイント、漁獲▲25％、金利＋１ポイント。元データを変更しない。
- 住宅家賃・土地は非課税扱い、事務所家賃・建物・費用は10％。住宅に係る仕入税額控除の按分を省略するゲーム簡略化を画面で明示。
- 法人税概算と個人の生活余力を常時表示。法人税概算には欠損金・調査による時期差の調整を反映。
- 経理・支出：期首の報酬設定、設備メニュー、実在庫処分、月２万円の丁寧な経理。レビューの７つの特別な選択を抽象的な帳簿結果として実装。私物は釣具か車の二択、生活費負担は個人余力１か月未満の月に１回。実務上の手順は扱わない。
- 調査：期末に翌期の月を予約。30か月目以降、前回から24か月以内は発生しない。通常25％、特別な選択２回以上50％、重い指摘歴70％。指摘なし後３年は通常。通常３〜５年に１回という要望との整合のため、48か月を過ぎた期末では翌期を予約する（確率だけだと10年間来ない場合があるため）。画面に抽選確率は出さない。
- 各指摘に認める／説明する。用途に関する説明は丁寧な経理により通る可能性がある。売上抜き・架空支出・棚卸・時期ずれは説明で取り消さない。未回答は翌月に認める扱いと画面に明示。
- 調査決定は翌月の未確定帳簿へ計上、その翌月納付。加算税10％／35％。私的利益は役員賞与扱いの個人税20％（ゲーム概算）。独立した期中賞与支給コマンドは設けていない。資料不備の従来機能も保持。
- 棚卸・売上の期ズレは４月に戻し、税務補正は両年を通算。前期の不足と翌期の過大分を二重課税せず、必要なら未収法人税等・還付として記録。繰延売上はこの演出の仮受負債であり正しい売上計上の説明ではない。
- 巡航：４月に12/24/36か月。固定数量・価格、社長店番。先に実行と同じ経路を試算し、確定時だけその結果を採用。税務の特別な選択は引き継がない。調査、人員相談、物件案内、修繕・荒天、短期借入期日、２か月先の資金余力不足、120月で停止。巡航中の確定決算を再表示。
- M&A：120月決算後、８〜10期の平均EBITDA300万円以上、純資産2,000万円以上。負のEBITDAも含む。基準倍率３年＋増益１年＋安定１年。初回は倍率部分の75〜90％。希望0.5〜10年、0.5年刻み。正式提出２回、２回不成立後の救済なし。確認後に１回だけ個人預金へ加算。会社預金・会社売上は不変。
- エージェント画像はチヌクエスト２の「彼」。個人譲渡税・仲介料を省略し「売却額」と表記。
- 10年完走時の３軸300点、端末内自己ベスト。M&A代金は個人預金に含まれるのでスコアで再加算しない。旧120月セーブも未判定なら１回判定。旧帳簿は変えない。
- フリープレイの新規開始で乱数シードを１回生成、復元時は保存値を維持。物件・漁業・交渉の系列は独立。
- クエの接客1,000を据え置き、店長を900へ調整し、クエが最高という既存希望に合わせた。これに伴う既存２試験の期待値だけ更新。
