# v37: 画像で追加された指示への対応

## 実装した仕様

- 月次レポートは「クエの一言」と「決算書・試算表」の折りたたみを独立させ、どちらも最初は閉じる。決算書側は、開いてから表のボタンを押す二段階。解説を開かなくても表に到達できる。
- 採用月は社長の接客力０。採用されたスタッフはその人物・職種の通常接客力で営業し、給与は満額発生する。翌月の販促・銀行相談でも在籍スタッフの接客力を使用する。
- 採用候補はお肉・ウサギン・ホフク・段ボール男から月替わりで２名。既に在籍する人物は除外。保存されたシードと月から決まり、画面の再表示や再読み込みで引き直さない。
- 各人物には接客力係数、集客寄与、事務による雑費節約の差がある。採用画面には数値を表示しない。職種変更・社員登用でも人物を保持する。既存の人物未指定スタッフは従来の職種能力を保持する。
- 銀行コマンドは創業時から相談可能。少女Aの画像を「銀行員A」として使用。確認して相談すると、その月の社長の行動を１回使用する。相談だけで融資・利息は発生せず、月の確定は通常のボタンで行う。同月の再表示は追加消費なし。確定済み・行動使用済みの月は資料閲覧のみ。
- 投資不動産は連続する２期の年次税引後利益がいずれも正の場合に解禁。月次黒字、借入、ゼロ利益は条件を満たさない。一度解禁したコマンドは保持するが、融資審査は購入時の財務内容で別途行う。サーティーの画像を「サーティー不動産」で使用。
- 販促・接客改善と大会協賛は、実行月は効果なし。翌月100％、翌々月100％、３か月後2/3、４か月後1/3、５か月後０。広告の直接効果を基礎集客力へ恒久加算しない。
- 販促で実際に来店・販売があった場合の認知の蓄積は別に保持する。継続的な営業による中長期の成長を残すための仕様。品揃え不足や長期の営業努力不足による低下は従来どおり。
- 値下げセールの翌年同時期のリピーター効果は、従前の明示仕様として別に維持する。
- 新しい操作を保存・復元およびサーバー再生へ追加。ランキングのルール識別子は `v37-1`。

## 検証

自動テストは、実HTMLを読み込むDOM操作テストと会計エンジンのテストを含む。全116件合格。Cloudflareローカル環境の画面配信・D1・１ターン再生・アクセス権検証も合格。今回の追加テストは６件：人物候補の再現性と採用月売上、隠し能力、銀行相談・保存・再生、販促期間、不動産解禁、実際のボタン経路と画像表示。

10年分の操作をクライアントとサーバーで再生し、会社預金・個人預金・評価の一致を確認する既存テストも対象。これらは描画エンジンによるスマートフォンの通し操作テストではない。
