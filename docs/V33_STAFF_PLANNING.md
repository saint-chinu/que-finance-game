# v33：社員登用の12か月比較

## 入口と判断

「スタッフ」の各バイトに「登用・継続・外部採用を比較」を追加。登用確認画面からも開ける。相談前から利用でき、相談前の登用案は相談発生月まで待つ。月次確定後は次の未確定月を開始月とし、実際の登用は未確定月の条件確認と確定を経由する。

3案を同じ開始状態・期間・営業方針・価格・推奨仕入で比較する。

1. 相談済みなら初月、未相談なら相談発生月にバイトを正社員へ登用。
2. バイトのまま勤続4年まで継続し、その後は補充しない。
3. バイトの退職後、最初に採用できる月に外部社員を採用。

外部採用は社長の当月行動を使用し、採用月は接客力半分・給与満額という本編仕様を反映。登用は勤続を引き継ぎ満額・全接客力。対象以外のスタッフも通常どおり勤務・退職し、自動登用はしない。

## 表示

- 通常需要と15％下振れのそれぞれで、3案の税引後期間損益、全従業員の給与＋会社負担社会保険、最低月末預金、終了時預金を比較。社長の役員報酬は従業員人件費欄に含めず、損益・預金には反映。
- 月次詳細は年月・税抜売上・税引後損益・人件費・預金・接客数／来店数。人員変更月と延期理由も表示。
- 営業方針は11月・2月接客改善／毎月店番／毎月営業・協賛（店番なし）。価格は本編と同じ4択。すでに実行した当月の投資・採用の行動ロックを優先。
- 本編の仕入・在庫廃棄・季節・固定費・カード回収・銀行返済・法人税・消費税・税務調査・個人生活費・隠し能力を使う。隠し能力の数値は表示しない。
- 試算中に支払不能ならそこで停止し、何月に会社預金／生活費が不足したかを表示。120か月の経営終了も超えない。短期終了した案を12か月分と見せず、期間不一致を明示。
- 月末残高比較であり、月中の入出金順序による資金不足は判定しない。新規設備・追加融資・不足資料の解消は自動実行しない。

## 多角化との関係・残課題

- 「次の事業用に残したい預金」を円で入力でき、最低月末預金との差額を示す。これは確保目標との比較であり、実際の資金移動・投資・利益計上はしない。
- **漁業・不動産賃貸の事業多角化は未実装**。v14文書にも後工程として残る。前回の未実装一覧から漏れていたため訂正。今回の試算は現行釣具店の人員判断で、多角化による売上・費用・資産は含めない旨を画面にも明記。
- 多角化の既定の開始条件・投資額・人員配置に関する確定仕様は、今回の現行ソース・文書・過去文脈検索では確認できなかった。漁業の設備・漁獲／天候・販売先、不動産賃貸の物件・入居／空室・修繕・返済、本業との社長行動や人員配置、事業別損益と全社B/Sの接続が今後の実装対象。これらの金額や収益を今回の比較に仮置きしない。
- スマホ全行程、実ブラウザでのバックアップファイル入出力は従来どおり最後の検証工程。
