# v31：税抜経理・カードまとめ買い・納付時の解説

## 確認結果

v30の時点で、税抜売上／商品原価と仮受消費税等／仮払消費税等は分離されていた。法人税等の計上・納付の一般説明もあったが、消費税の確定納付／中間納付の説明が弱く、販売シーンではP/Lの説明が優先されて消費税説明が表示されなかった。またカード会計は高額商品だけの商品単位判定で、消耗品とのまとめ買いを表現していなかった。

## 販売と入金

- 売上高は税抜、消費税は仮受消費税等。現金会計は税込で預金に入金、カード会計は税込で売掛金に計上し、２か月後に預金へ回収。
- 高額商品は竿・リール。販売した高額商品１点につき、販売済み消耗品を各種類最大１点までカード会計へ割り当てる簡略モデルに変更。消耗品単独の会計は現金。
- これは決済方法の割当だけ。販売数量・単価・売上・売上原価・月次の消費税合計は増やさない。現金の一部が２か月後の入金に移る。
- 売上は商品別に先に販売数を確定し、現金分／カード分の税抜額・税額を分ける。消費税は既存の商品別月次概算を保持し、分割による二重計上や合計額の変化を防ぐ。カード手数料・実際の請求書単位の端数処理は省略。
- 商品別のカード数量、税抜額、消費税、税込売掛金を月次報告に表示。初月は展開し、その後は詳細表示から確認可能。
- 税抜３万円の竿と550円の仕掛けの例：売掛金33,605円／売上高30,550円・仮受消費税等3,055円。回収は預金33,605円／売掛金33,605円のみ。
- 古い確定済み仕訳・売掛台帳は変更しない。新しい月次処理から適用し、予測と投資試算も同じエンジンを使う。

## 解説の表示場所

- 初めての販売仕訳シーンに税抜売上・仮受消費税等・税込売掛金・まとめ買い・２か月後回収を追加。仕訳ログの再生でも読める。
- 商品仕入の解説に、税抜の商品と仮払消費税等の合計を預金から支払うことを追加。
- 法人税等の納付は「未払法人税等／預金」。決算計上済みなので納付で費用を重複計上しないことを実際の金額で表示。
- 消費税の確定納付は「未払消費税等／預金」、中間納付は「仮払消費税中間納付／預金」、還付は「預金／未収消費税等」を別々に説明。
- 納付・還付がある月は毎回、月次報告に説明を表示。学習済みで仕訳アニメーションを省略しても消えない。
- 常設の「試算表・B/S・P/Lの読み方」にカード会計と税金納付の説明を追加。
- 科目名の「等」は地方消費税を含むことを明記。現金仕入の仮払消費税等と、中間納付の仮払消費税中間納付を区別する。
