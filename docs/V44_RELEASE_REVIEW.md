## 修正

1. 船員給与28万円・減給後給与がバックアップ検証に拒否される問題。正規の給与と2割減額の組み合わせを受理し、不正な給与は拒否します。
2. 初回採用の直後に追加応募が来る問題。初回採用月を保存し、以降の応募間隔を4〜6か月に固定します。退職・船の撤退後も初回採用扱いに戻りません。
3. 旧セーブの配置変更による能力半減が残る問題。配置変更・旧セーブ移行時に解消し、撤退時の店舗への配置でも新たな半減を付けません。
4. 船長に昇格しても減給フラグが残る問題。昇格時に減給情報を解除し、旧船員給与に戻されないようにします。
5. 経営メニューが白地に白文字となる問題。ヘッダーから継承する文字色を明示的に上書きしました。
6. 存在しない旧ホスティング設定を要求する既定ビルド、Windowsで動かないローカル検証手順、現在の画面と一致しない旧UI検証を修正しました。

ランキングのルール識別子は `v44-release` に更新。旧版と新版のチャレンジを同一のルールとして処理しません。
