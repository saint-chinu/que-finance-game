# v24 修正記録

v23 のレビューで再現した五件を修正した。

1. 4月の貸借対照表も試算表と同じ前月末（3月決算後）の残高を比較基準にする。損益振替前の値との混在をなくした。
2. 年次決算書を選ぶと、見出し・期末預金・比較説明を選択した3月決算期へ合わせる。月次の資金内訳とクエのぼやきは年次表示では隠し、現在の会社預金はゲーム上部に残す。
3. 仕訳の再生中に再読込した場合、先に仕訳ログを復元し、その上に再生画面を戻す。再生完了時はログへ戻し、閉じた後にスクロールも戻す。
4. 開業時に学習済みの仕訳は消費税分も含めて記録する。初月の新しい仕訳は販売・運営費・償却のまとまりをその場でB/S・P/Lへ反映し、通常導入から3クリック以内で試算表へ進める。個別仕訳はログから従来どおり再生できる。
5. 銀行の増額提案は契約ボタンではなく、提案額で再審査するボタンにする。連動する投資計画は新しい借入額・金利・期間で再試算し、画面に表示した条件と異なる場合は実行前に再審査へ戻す。再試算が失敗したときも実行を止める。

`tests/v24-regressions.test.cjs` に各経路の回帰テストを追加。既存の会計・融資・商品・経営バランスのテストと DOM 契約テストを通した。モバイルのB/Sは両側の表を同じ高さに伸ばし、資産合計と負債・純資産合計を下端で対応させる。実機のブラウザ表示は今回の自動テストに含まない。
