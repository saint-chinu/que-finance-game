# 月末の最後の資金繰り対応

月末の営業、生活費、返済、納税等を計算した結果、会社預金または個人預金が負になると、経営終了を確定せず `cashCrisis.status = pending` として進行停止する。既存の `ended` は停止ガードとして true を維持するが、画面は「最終対応待ち」と表示し、資金調達を断念して初めて failed にする。

## 対応

- 銀行に緊急相談：追加ターンなし。通常の審査点数・金利・枠を使う。資金不足だけによる自動否決をこの場面に限り外すが、収益力・純資産・役員貸付等の評価は維持する。
- 利用できるのは短期運転資金と、条件を満たす2年目の創業赤字補填融資。設備融資の流用不可。今月すでに銀行融資を実行していれば追加実行不可。
- 個人預金の投入：保有額以内を指定し、預金／役員借入金として記帳する。個人資産の任意評価や売却機能は設けない。利益・資本金は増やさない。
- 個人生活費の不足：会社に資金を確保できた場合、役員貸付金／預金として不足分だけ補填する。会社から借りた分は次の審査に反映する。
- 一部投入後に銀行相談するなど、異なる調達方法を併用できる。必要額が埋まるまでは停止する。
- 調達を断念する場合は二段階の終了確認を行う。画面を閉じても救済を放棄したことにはならず、メインボタンから再開できる。

## 整合性

売上・需要乱数・費用・税金は再計算しない。資金調達仕訳だけを当月へ追加し、試算表、現金増減、個人不足、当月履歴を更新する。借入利息と返済は翌月以降。銀行借入や社長貸付の記帳で不足がなくなれば resolved として再開する。120か月目も救済後に採点・M&A判定を可能とする。

保存・復元、操作リプレイ、ランキング用サーバーの再計算に対応。操作の審査はサーバーでもやり直し、クライアントが指定した融資承認は受け付けない。

検証：実際の資金不足に至るプレイ、社長貸付による救済、部分投入、銀行承認・過大額否決、同月二重借入防止、個人生活費補填、保存復元、120か月目、画面操作と決算表示更新。

月末確定前の仕入の見直し・資金不足警告も維持する。確定後に仕入や売上を巻き戻すことはできない。
