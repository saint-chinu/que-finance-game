# v30：保存・決算の振り返り・目標・欠損金繰越

## 今回の対象

以前に挙げた残タスクのうち、セーブのバックアップ／復元、年次・経営終了時の振り返り、目標と達成演出、法人税の欠損金繰越を実装。スマホの実操作・画面表示の通し確認は、ユーザー指定どおり最後に行う。

## バックアップ／復元

- 「セーブ」からJSONファイルをダウンロード。導入画面にもファイルからの再開ボタンを設ける。
- 会計残高・在庫ロット・借入・売掛・税金・履歴・選択中の仕入・仕訳学習／再生・目標確認状況を保存。自動保存の障害時も現在のメモリから書き出せる。
- 復元ファイルは16MBまで。形式、対応バージョン、数値、科目、連続した月次履歴、在庫・借入・売掛台帳と貸借の整合を検証。マークアップやプロトタイプ汚染キーを拒否。
- 選択後に対象年月・確定状況・会社／個人預金・経過月数を表示。明示的な復元ボタンまで現在のセーブは変更しない。
- 復元直前のセーブをブラウザに１世代保管してから置き換える。どちらかの書込に失敗した場合は元セーブを保持。復元直前のファイルもダウンロードして戻せる。
- 本機能は手元のファイルによる移行。サーバーへの自動同期ではない。

## 決算・経営終了時の振り返り

- ３月の月次確定後、初回に年次レビューを表示。「決算の振り返り」から各期を再選択できる。
- 売上・粗利／粗利率・税引後損益・預金増減・最低月末預金・銀行借入・自己資本・商品・売掛・廃棄・営業努力の月数・最良／最悪月を帳簿から集計。
- 各期について `期首預金＋実際の入金−実際の出金＝期末預金` を表示。初年度は設立前の０円から株式払込と開業支出も含める。
- 前年との差、黒字なのに預金減少、廃棄、役員貸付、営業未実施など、実データで判断できる内容だけを助言する。
- 120か月完了と途中支払不能の両方に結果画面。途中の期は「期中」と明示し、年換算しない。累計損益に期中終了分も含める。
- 会社預金・銀行借入・自己資本・財務スコアと、個人預金／会社から借りた元金を分けて表示。借入入金を利益に算入しない。
- 未読の税務調査がある場合、そのダイアログを上書きしない。月次結果とメニューから経営結果を開ける。

## 目標

1. カード売上の初回入金
2. 最初の冬・３月決算を支払不能にならず通過
3. 初めての税引後年間黒字
4. ２期連続年間黒字
5. 累計創業赤字の回収
6. 常連の定着50％
7. 120か月の経営完了

履歴から達成時点を求めて保存後も再現。月次結果で未表示の達成を演出し、メニューから一覧を参照できる。達成報酬として預金・集客を増やす処理はない。動きの軽減設定では演出を静止する。

## 欠損金繰越のゲーム仕様

- 青色申告を継続する独立中小法人を想定。税引前損益を税務上の所得として扱う簡略モデル。
- 欠損金は翌期から10年間、古い年度分からその期の所得を限度に全額控除。法人税等自体を欠損金に含めない。
- 控除後所得800万円以下25％、超過部分35％＋均等割７万円という既存のゲーム概算を維持。３月計上・５月納付。
- 繰越残高は帳簿外の税務情報。預金を増やしたりP/Lの過去の赤字を消したりしない。繰戻し還付、税効果会計、詳細な申告調整や実際の税率区分は省略。
- 年次レビューで税引前損益、欠損金控除、控除後課税所得、新規発生、翌期繰越残高を説明。目標画面でも現在残高を参照できる。
- 旧セーブは記録された税引前損益に同じ控除順序を当てて残高を再構成する。これは新ルールへの移行処理で、過去の確定税額・利益・納付を修正せず、過去税額の還付も行わない。再読込で二重生成しない。
- 参考：国税庁 No.5762（2026-09-29確認）
  https://www.nta.go.jp/taxes/shiraberu/taxanswer/hojin/5762.htm
