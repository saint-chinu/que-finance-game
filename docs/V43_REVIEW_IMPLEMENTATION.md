## 不具合・指摘への対応

## 採点の詳細

帳簿上の損益と評価用補正は区別する。各期の補正経常利益＝経常利益−受取利息−その期の新規役員貸付実行額。元金を繰り返し毎年費用扱いにしない。３期平均と10期累計を同じ補正で計算する。元金返済を利益として加点しない。

財務健全性は補正自己資本比率と債務償還年数が各50点。社長資金投入／救済銀行融資があった年度は重複せず５点減。役員貸付金／補正純資産が５％未満なら10点、20％未満なら25点、それ以上なら40点減。未収利息が残ればさらに10点減。各得点は０〜100点。

M&Aの純資産も役員貸付・未収利息を控除し、３期EBITDAから各期の新規役員貸付実行額を控除。営業実績を高く見せるため生活費を貸付へ付け替える抜け道を抑える。新規役員貸付控除はゲーム採点上の保守的な調整であり、実際の会計費用ではない。

## 船・人員・撤退：今回採用した暫定値

- 船の用途は「漁業」「釣船」。同じ設備を使う。４月に１回、行動を使わず切替。
- 釣船：船長１人＋船員１人以上。通常20日、抑制12日。荒天は出船ゼロ。６人／日を基準に店舗の集客・季節・天候で乗船客を計算。１人税抜9,000円、消費税10％、当月現金収入。燃料12,000円／出船日、乗船準備500円／人。維持・保険等は船共通の維持費に含める。
- 乗船客１人は同月の店舗来店数を１人増やす。店の接客上限と商品在庫は別に必要。来店を売上へ直接変換しない。
- 店舗３人、船長１人・船員２人まで。異動は月１回／人、行動なし、異動月能力半分。給与は本人の元職種を維持。給与と社保は勤務部門へ計上。
- バイトの登用・４年退職の時計は船への異動後も継続。船勤務中の登用は多角化メニューから可能。
- 船長の外部採用はマダイ。船員経験24か月以上なら船長の空席へ登用可能（ゲーム上の資格取得を含む簡略化）。登用後は月35万円。
- 休業：維持費税抜８万円→４万円、燃料・漁具・乗船準備費ゼロ。給与・償却は継続。連続７か月以上の休業時だけ償却を調査候補とする。断続的な低稼働の年間判定はまだない。
- 船員の退職予約は行動なし、当月給与を払って翌月から停止。予約後の異動は不可。
- 撤退は１行動。売却額は月と保存シードで固定。売却・関連融資完済・敷金返還・費用支払を一括処理し、預金不足なら何も変更しない。救済待ちの撤退は不可。
- 船売却：簿価×max(40％,70％−保有年数×２％−乱数×15％)。不動産：取得価格×max(20％,1−保有年数×年率１〜２％)×市況0.85〜1.10。仲介費用税抜３％＋６万円。
- 原価と減価償却累計額を落とし、差額と仲介費用を特別損益へ。税引前・純利益・純資産・法人税に反映し、経常利益と設備返済原資には混ぜない。土地と建物は分け、建物／船の売却消費税は通常の納付予定へ。
- 売却後の船員は店舗の空き枠へ移る。入れない人も当月の給与を支払い、翌月退職。船の再購入、全物件売却後の不動産再参入は翌期から。
- 過去の部門仕訳と３期EBITDAは消さない。撤退した部門の過去の実績も連続決算に残る。

## 意図的に保留した調整・制約

1. 価格の品目別弾力性は未変更。現行は竿・リールが定価固定、値付け対象は消耗品。元レビューの「竿・リールも一律１割値上げ」という読み方は現行コードと異なる。常時値上げが有利すぎるかは、給与・生活費を同一にした追加比較が必要。
2. 船・釣船の収益性、内部登用の見返り、保管費の強度は暫定。単体機能の正しさを確認したことと、最適なゲームバランスに到達したことを混同しない。
3. 住宅用消費税はゲーム全体の簡略ルール。実際の建物取得には取得価額等の条件があり、このゲームから実務上の控除可否を判定しない。
4. 旧ランキングの再生版とは別の `v43-review`。v42のランキング操作記録を同じ得点として扱わない。スマホ実機での全10年通し、GitHub／Cloudflare本番公開は未実施。
5. この版の長期プレイは撤退を最適化するAIではない。早い参入で失敗した結果は、その戦略の結果であって「多角化は必ず失敗する」という意味ではない。
