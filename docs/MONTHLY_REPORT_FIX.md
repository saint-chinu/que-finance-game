# 月次画面と販促月の検証（2026-09-30）

## 変更

- 月次報告の「クエの一言」は初期状態で１行の閉じた見出し。月次チュートリアル、ぼやき、会計の読み方をまとめた。
- 「試算表・決算書」も初期状態では閉じる。開いたあとも帳票本文は非表示。試算表・B/S・P/L・連続決算書・銀行審査のボタンで表示。同じ帳票ボタンを再度押すと非表示。
- コメントと帳票は独立。帳票のためにコメントを展開する必要はない。月次画面を開くたびに折り畳み状態に戻す。
- 最初に見える数字は釣具店の税抜売上、当月損益、月末預金の３項目。年次・銀行・トレンド表示中は月次サマリーを隠して期間の混同を防ぐ。
- 店番担当・接客上限・税抜売上見込みを行動選択の近くに明示。
- 予測販売数量が０なら、月次確定前に「店番なし」または「在庫・需要不足」を表示。見直しでは預金・ターンは動かず、明示的に確定を選んだ場合だけ通常の月次処理へ進む。

## 売上ゼロの調査結果

現行v35エンジンではスタッフの接客能力は社長の店外活動と独立。外出時もバイト400人、社員800人、店長900人分の接客能力が残る（採用月は半分）。販促・接客改善はクエ自身も８割の接客力で営業する既存仕様を維持。

実HTMLと全スクリプトを読み込んだDOMイベントテストで、採用ボタン→採用確認→月次確定→翌月→保存データ再読込→協賛／改善ボタン→月次確定を各職種で確認。６通りとも販売あり、税抜売上と売上高の仕訳が一致、給与・販促費も計上、貸借一致。

報告された「バイト・社員がいて販促を選んだのに売上ゼロ」は、この標準手順では再現していない。原因を断定して売上計算やバランスを変更してはいない。該当セーブの在庫・接客・選択行動・確定済み月を確認すれば追加調査できる。画面と予測に理由を明示し、意図せず０売上で確定する経路に確認を追加した。
