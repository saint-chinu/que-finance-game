# 公開実務資料を参考にした銀行審査モデル

2026-09-29更新。旧「基本60点＋売上・利益・預金の増減加点」は廃止。

## 実務資料との関係

- 日本政策金融公庫『経営改善計画書策定の手引』 https://www.jfc.go.jp/n/service/pdf/keieikaizentebiki_190801n.pdf : 経常利益＋減価償却費による返済原資、要償還債務÷返済原資、資産内容・借入・収益の確認。
- 経産省ローカルベンチマーク https://www.meti.go.jp/policy/economy/keiei_innovation/sangyokinyu/locaben/index.html : 成長、営業利益率、自己資本比率、営業運転資本回転期間、EBITDA有利子負債倍率等の分析。
- CRD協会 https://www.crd-office.net/CRD/service/scoring/index.html : 財務データとデフォルト実績に基づく統計的信用リスク評価。ゲームはCRDに接続せず、同モデル・PDを再現していない。
- CRD-BS企業評価ポリシー https://www.crd-office.net/CRD-BS/service/mcsspro/notice.html : 同社評価も銀行の財務格付そのものではない。
- 金融庁『経営者保証に関するガイドラインQ&Aの主な概要』 https://www.fsa.go.jp/common/paper/25/zentai/03.pdf : 法人・個人の分離、事業上不要な経営者貸付を行わない考え方。ゲームの一律40点減点の根拠数値ではない。

## 採点（境界値・配点は学習用。公式評点ではない）

直近確定年度のP/Lと現在のB/Sで計算。業種別統計で較正したモデルではない。

| 指標 | 算式 | 段階的得点 |
|---|---|---|
| 自己資本比率（25点） | 純資産/総資産 | 40%以上25、20%以上20、10%以上12、0%以上5、負数0 |
| 債務償還年数（25点） | 長短借入金・役員借入金/(経常利益+償却費) | 3年以内25、5年以内20、10年以内12、15年以内5、超過0。返済原資0以下も0 |
| 営業利益率（20点） | 営業利益/売上高。受取利息は除外 | 10%以上20、5%以上16、2%以上12、0%以上6、赤字0 |
| 当座比率（10点） | (預金+売掛金)/流動負債 | 150%以上10、100%以上8、70%以上4、未満0。流動負債なし・当座資産ありは10 |
| 営業運転資本回転期間（10点） | max(0,売掛金+商品-買掛金)/(売上/12) | 1月以内10、2月以内8、3月以内5、6月以内2、超過0 |
| 売上増加率（10点） | 直近最大3期の前年比（最大2区間）の平均 | 10%以上10、0%以上8、-5%以上5、-15%以上2、未満0 |

未算定項目は対象外、取得点/対象満点×100に換算。初年度は前年比なしで90点満点。通期決算自体がない場合は総合点を未確定とし、創業計画の別審査が必要として両枠0。創業計画審査は未実装。

２期連続経常利益悪化-10。役員貸付あり-40（ユーザー指定の大幅減点）。未収利息あり-10。いずれもゲーム内の定性・トレンド補正。最終点は0〜100。預金増加だけを加点しない。実際の資産回収可能性を確認せずに役員貸付金を一律全額損失とは扱わない。

参考表示のEBITDA有利子負債倍率=(借入金-預金)/(営業利益+償却費)。分母0以下は算定不可、分子の負数は保持。債務償還年数と混同しない。

## 金利・限度額（ゲーム設定）

A 80点以上: 2.0%、短期掛目100%、設備10年分。
B 65〜79: 3.0%、80%、7年分。
C 50〜64: 5.0%、50%、5年分。
D 49以下: 新規融資不可。金利は固定ゲーム基準1.5%+上乗せ0.5/1.5/3.5%。市場金利や実際の金融機関の提示ではない。

短期総枠=max(0,売掛金+商品-買掛金)×掛目。役員貸付を含めない。
設備総枠=max(0,経常利益+減価償却費)×格付年数、最大10年分（ユーザー指定）。設備融資の実行時は設備代金も上限。
追加可能額=max(0,総枠-対応する借入残高)。短期借入と長期借入を対応させる。枠超過を表示し既存契約を自動変更しない。
純資産0以下・預金負数もゲームでは新規実行停止。実際の一律否決基準ではなく再生支援等の個別審査は未実装。

## 対象外と検証

同業小売業との統計比較、担保・保証、返済履歴、事業計画の個別評価、創業融資、融資実行・返済処理は未実装。採点結果は銀行の格付け・承認やCRDのPDではないと画面にも明示。
財務比率、貸付金減点、データ不足、ゼロ除算、利益悪化、既存債務感応度、10年枠上限を検証。

## 個人生活費・役員貸付

手取り240千円、生活費初期200千円。個人資金不足を会社預金の範囲で貸し付け、1年以内返済約定の流動資産として表示。会社預金不足で賄えない額は個人預金の負数で表す。月末元本×ゲーム約定年利1.3%/12を円単位四捨五入して未収利息/受取利息。設定に従い個人預金から利息・元本を回収。元本回収は収益にならない。

国税庁 No.2606 https://www.nta.go.jp/taxes/shiraberu/taxanswer/gensen/2606.htm を参照。無利息・低利は原則給与課税、合理的利率や年間利息差額5,000円以下等の例外あり。未収利息を自動的な追徴税額と扱わない。年1.3%は固定ゲーム設定で将来の税務利率を保証しない。
