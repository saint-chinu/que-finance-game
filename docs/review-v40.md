# v40 決算コメントと経営パターンの検証

## 検証してから変更した点

既存のぼやきは原則3か月おき、前年比を参照していなかった。赤字縮小・黒字減益・初年度・月次比較・スタッフヒントとの同時表示をテストし、旧実装で要求を満たさないことを確認してから変更した。

- 確定した毎月に短い損益コメント。月次は前年同月の月間損益、期末は前年の年間損益と比較する。累計と月間を混ぜない。
- 赤字改善、赤字拡大、黒字転換、赤字転落、黒字増減、横ばいを区別。初年度や比較記録のない場合は前年比を捏造しない。
- 年間赤字が2期連続で縮小した場合は継続的な改善として言及する。
- 年度末は資金不足、役員貸付金、廃棄、人件費負担、滞留在庫、営業放置、売上減少、粗利率の順で該当するヒントを1つ添える。原因の断定や隠し能力の漏えいはしない。
- 半年経過のスタッフ能力の示唆は決算コメントと共存。未確定の試算にはぼやきを出さない。
- 月次の状況コメントにあった前月売上との比較を前年同月に修正。冬の季節減少をそのまま営業努力不足と扱わない。
- 既存の折りたたみ表示は維持する。

## 追加の比較検証

`node scripts/verify-v40.cjs`。3方針×共通3シード。資金注入や需要先読みなし。既存の15方針検証と同じエンジン・初期条件・採用候補選択。全月で会計整合性を検査した。

|条件|最終点（M&A後）|基準シードの最終預金|基準シードの累積廃棄損|
|---|---:|---:|---:|
|店舗設備拡大＋内部登用|217〜225|3,004万円|10.1万円|
|同じ設備拡大＋登用せず再採用|239〜240|3,468万円|10.2万円|
|設備拡大＋内部登用＋夏の発注量を冬も維持|241〜246|3,647万円|11.1万円|

内部登用は同条件でも収益面で不利になった。需要が接客能力を使い切らないため、人件費増に見合うかの試算が必要。ただし社員登用には接客容量・集客・事務の実効果があり、計算漏れは確認されていない。今回、賃金や能力を恣意的に変更していない。

夏の発注量を冬に維持しても、容量制限・FIFO販売・保存可能期間の範囲で在庫が消化される。今回の条件では廃棄損の増加は小さく、むしろ欠品抑制で成績が上がった。「仕入を増やせば冬に必ず破綻する」というバランスにはなっていない。ただし試算は預金と容量を守る発注であり、借入までして過大仕入する行動は未検証。廃棄率を一律に増やす修正は行わず、在庫・廃棄の実績に応じたぼやきを追加した。

## 現状での王道と失敗

王道は初期の固定費を抑え、営業努力・品ぞろえを維持し、黒字が安定してから預金余力を残して設備を増やすこと。採用・登用は能力不足や不在時の店番需要に応じて比較試算する。多角化は本業と返済余力が整ってから。

失敗は営業放置、創業直後の重い人件費、売上に見合わない高額販促、粗利を見ない値引き、返済余力を見ない不動産購入。赤字だけを失敗扱いせず、前年比の改善と現預金の両方で判断する。
