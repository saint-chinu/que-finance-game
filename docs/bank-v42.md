# CF審査と短期資金の３か月更新

## 融資判定

ゲーム内の簡易CFは経常利益＋減価償却費。会計上の赤字だけを理由に否決しない。ただしCF黒字も無条件の承認ではなく、スコア・純資産・既存債務・目的別枠の制約を受ける。赤字額をそのまま無条件に貸す仕組みは設けない。

設備資金は直近年度の簡易CFがプラスであることを追加条件とし、既存の返済原資・設備価格・耐用年数による上限を維持する。

短期運転資金は売掛金＋商品−買掛金を裏付けとし、既存の短期借入を控除する。CFが赤字でも、通常のスコア等の条件に加えて運転資金回転期間３か月以内・自己資本比率20％以上・流動比率100％以上・役員貸付金および未収利息なしを満たす場合は対象とする。これらはゲーム内の判定閾値であり、すべての実在銀行共通の基準ではない。

従来の２年目の創業支援枠は150万円・最長５年を維持し、直近２か月の月次純利益黒字条件を月次CF黒字に更新。CFに既存支払利息を戻し、既存元利返済を控除した余力で新規元利返済を賄える額に限定する。

## 短期更新

新規短期借入は３か月後に元金一括返済。期日の前月・当月に更新でき、更新すると元の期日から３か月延長する。旧セーブの既存期日は勝手に前倒しせず、次の更新から３か月にする。

|選択|行動消費|資金移動|
|---|---|---|
|同額|なし|なし|
|増額|承認・否決ともあり|承認時のみ差額を入金|
|減額|なし|差額をその場で返済|

同額・減額も現在の審査枠を超える更新は承認しない。元本を０にする返済は財務格付けにかかわらず可能だが、返済資金が必要。増額は明示的な確認後に審査し、否決時にも行動を使った状態を保存・リプレイする。元本と期日は否決時に変わらない。増額申込みは同じ月に１回。新規借入と同月の追加増額も不可。増額分の利息は翌月から発生する。

銀行メニューと審査資料画面から、行動を使う相談を経ずに同額・減額更新へ進める。増額は「否決でも行動を消費・社長は店番できない」と確認画面に表示する。

検証：赤字CF黒字／赤字CF赤字の運転資金条件、３か月満期、同額更新、差額返済、増額承認と否決、二重申込み、行動消費の保存、元利金の二重計上防止、実画面の警告、サーバーリプレイ。
