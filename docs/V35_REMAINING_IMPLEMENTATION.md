# v35 — 自店供給・多角化校正・公開ランキング

## 実装

### 漁業から自店への供給
- 生け簀を持つ会社は毎月０〜300匹を上限として活きアジを自店へ原価供給できる。
- 月末に漁獲から振替し、翌月から釣具店で販売。10匹を1kg相当として、外販kg・供給匹・鮮度ロスkgの数量を保存する。
- 振替は「商品／売上原価」。社内売上・社内消費税は計上せず、借方在庫は釣具店、貸方原価減は漁業へ帰属する。
- １匹80円の標準原価。配賦燃料費との差額を、選別・輸送・飼育準備の実支出として計上。元の漁業原価と二重に費用計上しない。翌月の死亡ロス・販売原価は既存の商品処理につながる。
- 生け簀容量・現在庫・漁獲量で供給量を制限。不漁時に架空の在庫を生まない。補充案は移管済み在庫を見て外部仕入を減らす。
- 全社の預金・借貸・在庫・部門利益の検算を保持。事業別画面に社内受入・供給の参考額を併記（全社合計には足さない）。

### 多角化のゲーム性
- `scripts/balance-v35.cjs` で３seed×７方針の120月試算を実施。結果は `V35_BALANCE_RESULTS.json`。
- 基本の単店堅実は年２回改善、営業放置は改善なし。拡大案は役員報酬18万円・生活費12万円、年３回改善という資金確保の前提を明示。
- 釣具店拡張、漁業、物件投資を別々に確認。混合案は店舗を第３期に拡張し、漁業は第５期以降・資金600万円を残せる時期まで待つ。早期に両方を買う試行は資金不足となったため、成功案では順序を変更。
- M&Aの提案閾値は引き下げていない。店舗中心・漁業・段階的な混合案で到達を確認。M&Aは完走の必須条件ではない。
- 築古高借入案は返済と修繕で資金が厳しくなる。全案件が儲かる調整にはしていない。
- 初年度赤字／２年目改善／３年目以後の回復という既存曲線は維持。拡大案の低報酬・低生活費はプレイヤーが選ぶ戦略で、通常プレイに強制しない。

### 公開ランキング
- 同じSiteを静的配信からWorker＋D1へ拡張。URLと通常プレイの保存キーを維持。
- 月替わりシナリオは日本時間の年月とルール版から固定seedを生成。利用者が任意のseed・残高・点数を登録するAPIは設けない。
- ランク対象は新規チャレンジのみ。旧セーブ・通常プレイはそのまま続行可能、通常の自己ベストも保持。
- ブラウザで行う操作を記録し、サーバーが同じ会計エンジン・銀行採点・物件審査で１操作ずつ再生。初期seedから検証済みの状態だけを次操作の入力に使う。
- 120月分の一括計算に依存せず、順次再生した状態をD1へ保存。全操作記録も保存し、最終点数・B/S・P/L・部門収支はサーバーの状態から生成する。
- 通信再試行は履歴番号と操作ハッシュで冪等化。状態更新は履歴番号による比較更新と操作の一意制約で重複を防ぐ。
- 不正な操作・未来月への飛越・勝手な融資条件・需要の上書き・個人預金の直接変更は受け付けない。
- 個人識別はブラウザのランダムなHttpOnly Cookie。サーバーにはハッシュを保存。本人確認を伴う実名ランキングではない。
- 閲覧は公開。登録は完走後の明示操作で、公開項目は表示名、３軸点数、個人資産額・売却額、最後の３期の決算、事業別収支、事業構成。操作履歴・仕訳ログは公開APIに出さない。
- 各ブラウザ・各シナリオの最高記録１件。上位30件と過去月を閲覧可能。同点は公開日時順。同じブラウザから公開を取り下げられる。
- 端末の点数を上書きしても順位は変わらない。ただし自動最適化プレイや複数ブラウザ利用を本人認証で制限する仕組みではない。
- Cookie削除・他端末へのバックアップ移動では公開記録の操作権限は移らない。履歴を巻き戻したセーブでサーバーの履歴を上書きしない。画面で制約を説明。
- 毎月のシナリオ切替はAPIの年月判定で行う。外部のスケジュール処理を必要としない。

### スマホ向け整理
- 多数のコマンドをネイティブの「経営メニュー」へ集約。ボタンは44px以上、入力は16px。
- 月次・比較表の科目列を固定し、横スクロールを表内に閉じる。B/Sの左右対照を保持。
- ダイアログを動的ビューポート内へ制限。物件カードは狭い画面で１列。
- 初回チャレンジで導入画面・操作不能状態が残らないよう解除。

## 検証

- 既存93件に、記録したUI操作の再生一致、不正な残高・融資入力の拒否、自店供給の数量・会計・原価整合、SQLiteでのAPI保存・再送・ブラウザ分離・公開・削除、120月の再生と点数一致、銀行スコア共通化の６件を追加。
- SQLiteの実データベースで生成したDrizzle移行を適用。SQLはスキーマのみ、APIはパラメーター化し、１prepareにつき１文。
- スマホ実機・ブラウザのタップ通しは未実施。Sitesの確認手順が指定するブラウザ操作スキルが、この環境の利用可能一覧にないため、別経路で代用して確認済みとはしない。画面生成と主要操作の自動検証、CSSの修正まで。

## 範囲

今回残るのは、実機でのタップ・スクロール・ダウンロード／復元の最終確認。漁獲の複数魚種・鮮魚の長期保管・不動産売却などは元仕様で未整理の別機能であり、今回の「活きアジの自店供給」に追加していない。
