# 融資の３案と少女A（2026-09-29）

既存の決算・スコア・格付け基準を利用。ゲーム設定であり実際の融資条件ではない。

- 銀行ボタン→運転資金または購入設備→控えめ50%／標準80%／大きめ120%を自動計算。1万円単位で切上げ、少額時も異なる３案。
- 運転資金は必要運転資金から既存短期借入を控除した額が基準。設備は実際の購入代金が基準。
- 判定：通期なしは保留、スコア・資本・現金条件不適合は否決、希望額が追加枠を超えれば過大。少女Aが該当理由・超過金額を説明。枠超過では上限への減額再申込みが可能。
- スコア80点以上・余力ありの場合、上限までの増額を提案。元の希望額・増額・辞退をプレイヤーが選ぶ。自動借入なし。
- 金額と利率、初回利息、返済方法を表示して確定後に入金。月１回、確定月は相談のみ。再判定で古い条件による実行を防ぐ。
- 短期：翌月から月利息、12か月後元金一括。長期：翌月から元金均等、格付け別5/7/10年。端数は最終返済調整。設備は購入を同時実行し、既存設備や前提未達は実行不可。
- 仕訳：預金／短期借入金（または長期借入金）、返済は借入金／預金、利息は支払利息／預金。設備取得は従来の什器・内装／預金。
- 融資入金・元金返済・支払利息を資金収支に個別表示。営業利益の採点から支払利息を除外。月次仕訳ログ・初回アニメーションに連携。
- v4セーブを維持。loans等の新規フィールドは借入時に追加。

確認：既存12テスト、融資5テスト、DOM契約スモーク。13か月の元利返済、貸借一致、資金収支一致、否決時不変、二重実行拒否を確認。実ブラウザ描画テストは未実施。
