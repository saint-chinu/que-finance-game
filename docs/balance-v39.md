# v39：15方針の10年間テストプレイ

2026-09-30。実際の月次エンジンを使用。15方針×共通の3シード（73129、91、202609）＝45プレイ。各月の現預金増減、貸借、在庫、借入台帳、売掛残高の整合性を検査。画面のタップ操作を通したテストではない。

## 修正

- 段ボール男の退職などで保管上限が低下しても、既存在庫を販売して月を進められる。上限を超える保管区分への追加仕入は不可。既存在庫を勝手に廃棄しない。
- 投資試算が120か月で切れる場合、希望期間と実際の期間を表示する。期間外の投資計画をエラーにする。実際の画面表示も回帰テストで確認。

## 比較条件

初期資本金・初期設備は通常の新規ゲームと同一。資金注入、需要の先読み、隠し能力による人物選別はしない。最初の2方針は初期設定の報酬・生活費。それ以外は役員報酬18万円、生活費12万円。基本は推奨仕入・定価。方針名に示した変更だけを追加する。年3回改善は8月・11月・2月、年2回改善は11月・2月。採用は実際の募集条件に従い、提示候補の先頭を選ぶ。登用方針は打診時に登用。

設備投資は3年目から預金300万円を残せる場合に冷凍庫→生け簀→倉庫。不動産は5年目以降の7月、条件を満たし預金400万円を残せる場合に最安物件を購入（最大3件）。漁業は3年目から預金400万円を残せる場合に船を取得し、募集月に船長・乗組員を採用。銀行が認める範囲の融資を利用。仕入倍増は6〜11月、保管容量と預金の範囲内で推奨追加量の2倍を目指す。

M&Aが発生した場合は全方針共通で応相談→EBITDA4年分＋純資産→断られたら3年分、合意時に売却確定。非公開の上限額は参照しない。最終点は売却後、比較用に売却前の点も記録。満点300点（収益性100・健全性100・個人資産100）。途中終了は採点対象外であり0点とは扱わない。

## バランス上の所見

- 標準報酬・年2回改善は、基準ケースで初年度約154万円赤字、2年目約45万円赤字、3年目から黒字。狙っていた創業期の収支に近い。
- 店番だけは5年目、節約だけでも7年目に終了。営業努力を怠ると衰退する設計は機能している。
- 初期から社員を雇う、バイトを雇って高額販促を続ける方針は3シードとも資金不足。ただし需要が足りない状況での固定費増であり、採用した月の売上がゼロになる不具合とは別。
- 店舗設備を増やさないまま内部登用すると人件費負担が増え、基準ケースは6年目以降赤字。需要・処理能力に対して登用が妥当かを比較試算で強調したい。一律に内部登用を正解にする必要はないが、育成の見返りは再検討対象。
- 容量・資金の範囲内の夏秋仕入倍増では破綻せず、基準ケースは通常の年3回改善より預金が多い。この条件では「冬の過剰在庫リスク」が十分に現れていない。追加発注を冬も維持する方針や、生餌・高齢在庫中心の方針は今回未検証。
- 不動産は完走できてもシードによる点数差が大きい。借入負担・取得時期・物件条件を一つの点数だけで判断しない。
- 黒字でなくても無借金・高自己資本比率なら健全性100点になり得る。収益性は別枠で0点になる設計だが、合計点だけの表示は誤解を招くため内訳の説明が必要。

今回の変更は再現した2不具合に限定し、上記の結果を見てから難易度や採点式を勝手に変更してはいない。3シードは統計的な勝率の推定には少ない。各方針も最適解探索ではなく、明示したルールによる自動プレイ。
